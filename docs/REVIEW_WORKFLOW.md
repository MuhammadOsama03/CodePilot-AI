# Review workflow

1. Select Python, JavaScript, or TypeScript.
2. Paste non-sensitive source code within the configured length limit.
3. Run local heuristic review; inspect findings and severity counts.
4. Enable AI review only when the Gemini service is configured and the source can be shared with that provider.
5. Manually validate every suggested change before applying it.

The local scanner is intentionally incomplete. AI output may be inaccurate. Never automatically execute suggested code.
