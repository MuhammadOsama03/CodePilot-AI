# CodePilot AI

An AI-assisted code review workspace for developers. **Work in progress — early foundation only.**

## Vision

Paste source code, select a language, and request a review that highlights potential bugs, security concerns, readability, and performance opportunities. Suggestions will be reviewed by a human rather than automatically applied.

## Planned stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Python, FastAPI
- **AI integration (later):** Gemini API, with server-side key management
- **Persistence (later):** SQLite
- **Testing (later):** pytest and frontend checks
